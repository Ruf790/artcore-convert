# ArtCore Convert

Видеоконвертер для Windows на **FFmpeg** с интерфейсом на Qt. Четвёртая программа семейства ArtCore — рядом с ArtCore Client, [ArtCore Player](https://github.com/Ruf790/artcore-player) и [ArtCore Music](https://github.com/Ruf790/artcore-music).

*A video converter for Windows on FFmpeg with a Qt interface. English below.*

## Возможности

- **Окно:** слева задания карточками, в центре просмотр с лентой кадров и кривой громкости, справа вкладки Инфо · Метаданные · Главы · Обрезка · Потоки · Статус; сверху контейнер и пресет, снизу кнопки плеера, счётчик кадров и выбор потоков. На «Потоках» у видео и каждой дорожки свой блок: деинтерлейс, разрешение, частота кадров, цвет, кодек; у звуковой дорожки — свои кодек, битрейт, каналы и громкость.
- **Разрешение:** готовые размеры (2160p … 360p, DVD PAL / NTSC) или своё W×H; вписать, вписать с полями или растянуть; увеличение по желанию.
- **Фильтры видео (1.3)** — строки на «Потоках» (галочка · название · значение · ⚙): **Crop** (авто — поиск чёрных полос по нескольким местам фильма, или вручную; рамка видна на картинке), **Interlace** (bwdif / yadif, порядок полей, удвоение кадров, снятие телесина), **HDR → SDR** (zscale + tonemap или libplacebo; включается сам, если HDR не сохранить), **Rotation**, **Deshake** (deshake или vid.stab в два прохода), **Noise reduction** (hqdn3d / nlmeans), **Noise** (зерно), **Delogo** (прямоугольник рисуется мышью на просмотре), **Unsharp**, **Color correction / White balance**, **Pad**, **Aspect**, **Overlay** (PNG-логотип, водяной знак), **Pixel format, Color space** (4:2:0 / 4:2:2 / 4:4:4, 10 бит, BT.709 / BT.601 / BT.2020, TV / PC), **Framerate** (CFR / VFR, интерполяция). Работают и при обрезке на несколько кусков, попадают в «Скопировать команду ffmpeg» и в пресеты.
- **Фильтры звука (1.3):** задержка дорожки (+ / − мс), усиление в дБ (видно на кривой громкости), частота, разрядность, моно / стерео / 5.1 / 7.1 — для всех дорожек или у каждой своё.
- **Кодирование и задания (1.4):** **два прохода** для битрейта / размера файла (x264, x265, VP9, MPEG-4 / 2, SVT-AV1 где сборка умеет; NVENC — multipass в один запуск); **несколько заданий одновременно** (например, видеокарта и процессор параллельно); **ограничение процессора** «100% ▾» рядом с приоритетом (потоки ffmpeg / пул x265 и ядра); **метрики качества** PSNR / SSIM / VMAF по готовому файлу и **текущий кадр** на «Статусе»; **тест скорости** всех кодеров ПК (меню «Сервис»); задания перетаскиваются мышью, список заданий сохраняется в файл и загружается, вид «карточки / строки»; **внешние дорожки** (звук и субтитры из файла, с задержкой и языком); **склейка** нескольких файлов в одно задание (разные размеры и частоты приводятся к первому, глава на каждый файл); **разбиение** результата на части по размеру или времени. Всё работает вместе с обрезкой и фильтрами, попадает в «Скопировать команду ffmpeg» и в пресеты / очередь.
- **Пресеты и устройства (1.5):** **пресет формата** (⚙ у пресета): разрешённые кодеки, профили и уровни H.264 / HEVC / AV1 / MPEG-4 / MPEG-2, ключевые кадры (мин. / макс. GOP в кадрах или секундах, закрытый GOP), VBV, своё расширение файла, число звуковых дорожек и каналов, кадр и длительность по умолчанию; свои пресеты формата создаются, переименовываются, удаляются, экспортируются и импортируются файлом. **Параметры контейнера** (⚙ у контейнера): MKV — место под индекс, Cues в начале, кластеры, CRC32, флаг «по умолчанию»; MP4 / MOV — faststart, фрагментированный MP4; TS / M2TS — muxrate, PCR. **Пресеты устройств** в одном списке с группами: iPhone / iPad, Android, Samsung / LG / Sony, PlayStation 5, Xbox Series, YouTube, Telegram, Discord 10 / 50 МБ, Blu-ray H.264, DVD PAL / NTSC. **Расширенные настройки кодера** (🔧 у кодека): x264 / x265, NVENC (p1–p7, tune, multipass, B-ref, look-ahead, AQ, split encode), AMF / QSV, SVT-AV1, VP9 — показывается только то, что есть в этой сборке FFmpeg. **Сравнение двух пресетов** на коротком куске: размер, скорость, VMAF / PSNR / SSIM.
- **Логи (1.6):** ENCODING STARTED → исходник и его потоки (и внешние дорожки) → выходной файл и формат → Video / Audio general (разрешение «было > стало», аспект, фильтры, кодек с настройками) → каждый проход ffmpeg с командой → статистика потоков (прочитано / декодировано / закодировано / записано), параметры x264 / x265 из файла → ENCODING COMPLETED / FAILED / STOPPED, время, пик памяти, размеры данных и контейнера. История последних 300 — меню «Лог».
- **Стиль (1.6):** классический — плоские поля и кнопки, серые заголовки блоков, синие вкладки-сегменты; кнопки и иконки свои. «Современный» (скруглённый) — в Настройках. Карточки дорожек на «Потоках» сворачиваются как аккордеон: сняли галочку — закрылась.
- **1.8:** **кодирование кусками (кластерами)** — фильм режется на куски, каждый кодирует свой ffmpeg на своих ядрах (сколько одновременно и длина куска — в Настройках); готовые куски хранятся, и остановленное или прерванное задание продолжается с недоделанного куска, а тот же файл с теми же настройками берёт уже сделанные; **Blu-ray и DVD целиком** (Ctrl+D или бросить папку диска) — плейлисты / титлы с длительностью, частями, звуком и субтитрами, ★ основной фильм, языки дорожек и главы с диска; **демукс** — каждая дорожка в свой файл без перекодирования, ядро DTS из DTS-HD и AC3 из E-AC3; **Dolby Vision** переносится через x265 / SVT-AV1 (RPU кадр за кадром, с обрезкой и кусками), **HDR10+** — через hdr10plus_tool и x265; **оценка размера** по пробным кускам («CRF 22 ≈ 4,3 ГБ» и соседние значения); **EDL** (Kodi / MPlayer, DaVinci / Premiere CMX 3600, mpv) — загрузить и сохранить куски обрезки; **имя по шаблону** — `{title} ({year}) {res} {vcodec}`, папки для фильмов и сериалов.
- **1.7:** **окно лога** (Ctrl+L) — история слева (поиск, «только с ошибками»), лог справа с подсветкой секций и ошибок, поиск (Ctrl+F, F3), переход к следующей ошибке (F8); **«Применить настройки к другим заданиям»** — профиль и фильтры, дорожки (по порядку), обрезка — к выделенным или ко всем; **автоподхват** `film.*.ac3 / .srt / .ass` рядом с фильмом (вкл/выкл в Настройках); **«Слушать»** у внешней звуковой дорожки — фильм играет с ней и задержкой, задержка меняется на ходу; **до / после** (Ctrl+B) — шторка: исходник слева, результат справа (готовый файл или тестовый кусок 10 с); **пресеты NVENC для RTX 40/50** (AV1 / HEVC: p7, lookahead, temporal AQ; AV1 быстро — split-encode); **кроп** находит серые и шумные полосы, а отдельные кадры без полос (титры, тёмные сцены) больше его не отменяют.
- **Внешний звук и субтитры (1.6):** брошенные или открытые (Ctrl+O) вместе с фильмом `film.rus.ac3`, `film.eng.srt` прикрепляются к `film.mkv`; брошенные на карточку или картинку — к этому фильму; иначе спрашивается «добавить к фильму / отдельным заданием».

- **Кодирование на видеокарте:** NVIDIA **NVENC** (H.264, HEVC, AV1 — RTX 40/50), AMD **AMF**, Intel **Quick Sync**. При запуске программа сама проверяет, какие кодеры работают на этом ПК (кодирует несколько кадров), и в режиме «авто» берёт лучший: NVIDIA → AMD → Intel → процессор.
- **Кодирование на процессоре:** x264, x265, SVT-AV1, VP9 (libvpx), Xvid / MPEG-4 ASP, MPEG-2, Apple ProRes 422, GIF.
- **Форматы:** MKV, MP4, MOV, WebM, AVI, TS, M2TS (Blu-ray), GIF; только звук — MKA, MP3, M4A, FLAC, Opus, OGG, WAV, AC-3. Неподходящий контейнеру кодер или звук программа меняет сама и предупреждает.
- **Качество:** постоянное качество (CQ / CRF / QP), битрейт или **размер файла** (битрейт считается сам); ползунок «быстрее ↔ качественнее» для любого кодера; 8 или 10 бит; **HDR10 / HLG сохраняются** при кодировании в HEVC / AV1 10 бит.
- **Картинка:** уменьшение до 2160p…480p (только уменьшение), частота кадров, деинтерлейс (авто — для чересстрочного видео).
- **Звук:** копировать как есть или AAC, AC-3, E-AC-3, Opus, FLAC, MP3, Vorbis, MP2, ALAC, PCM 16 / 24 бит; стерео / 5.1; выравнивание громкости (EBU R128). «Авто» копирует звук, если он подходит контейнеру, иначе — его обычный кодек.
- **Обрезка:** просмотр на движке mpv (как в ArtCore Player) с шагом в один кадр, начало и конец куска клавишами I / O, сколько угодно кусков — оставить их или вырезать. Без перекодирования видео режется по ключевым кадрам.
- **Метаданные:** теги файла (название, год, комментарий и любые другие), язык, название и флаги «по умолчанию» / «принудительно» у каждой дорожки.
- **Главы:** свои названия и время, добавление в моменте просмотра, главы через каждые N минут; главы исходника сами сдвигаются по обрезке.
- **Дорожки:** у каждого файла можно убрать любые звуковые дорожки и субтитры или выбрать для дорожки свой кодек. В MP4 текстовые субтитры переводятся в MP4 Text.
- **Без перекодирования:** перепаковать MKV ⇄ MP4, оставить видео как есть и поменять только звук (например, DTS → AC-3 640 для телевизора).
- **Очередь:** файлы и папки (перетаскиванием или из меню Проводника «Конвертировать в ArtCore Convert»), у каждого файла свои настройки, пресеты (встроенные и свои), пауза / продолжение, остановка, повтор, приоритет ffmpeg, после очереди — открыть папку / сон / выключить ПК. Очередь сохраняется до следующего запуска.
- **Статус:** прогресс, прошло / осталось, скорость, кадры в секунду, битрейт, размер (и прогноз), загрузка процессора и памяти, свободное место, нагрузка и температура видеокарты NVIDIA, лог ffmpeg. Прогресс виден и на кнопке в панели задач.
- **Сведения о файле:** кадр из фильма, контейнер, длительность, видео (кодек, разрешение, fps, бит, HDR / Dolby Vision, чересстрочность), звук и субтитры с языками.
- Исходник никогда не перезаписывается; готовый файл появляется только после успешного кодирования (пишется в `.part`). Автообновление с GitHub Releases, RU / EN, тёмное или светлое оформление (или как в Windows), portable-версия.

## Сборка

Нужны Python 3.12/3.13 (64 бит) и Inno Setup 6.3+. `build.bat` скачает FFmpeg (BtbN, GPL shared) и libmpv (shinchiro), соберёт `.exe` и установщик.
На GitHub это делает CI: каждый push собирает установщик (Actions → Artifacts), а опубликованный релиз (тег `1.0.0`) получает `ArtCoreConvert-Setup-<версия>.exe` и portable-архив.

Запуск из исходников: `pip install -r requirements.txt`, FFmpeg в `PATH` или в `ffmpeg\bin\`, затем `python run.py`.
Тесты: `pytest tests` (нужен ffmpeg с libx264 / libx265 / libsvtav1 / libvpx; для вкладки «Обрезка» — libmpv).

## English

**ArtCore Convert** converts videos with FFmpeg: on the graphics card (NVIDIA NVENC, AMD AMF, Intel Quick Sync — found and tested at start) or on the CPU (x264, x265, SVT-AV1, VP9, Xvid / MPEG-4, MPEG-2, ProRes, GIF), into MKV, MP4, MOV, WebM, AVI, TS, M2TS, GIF or audio only (MKA, MP3, M4A, FLAC, Opus, OGG, WAV, AC-3). Trim with a frame-accurate mpv preview (any number of pieces, kept or cut out); edit file tags, track languages / titles / flags and chapters. Constant quality, bit rate or target file size; 8 / 10 bit with HDR10 kept; downscaling, frame rate, deinterlacing; video filters (1.3, rows ☑ · name · value · ⚙): auto / manual crop shown on the preview, deinterlace and inverse telecine, HDR → SDR tone mapping (zscale or libplacebo), rotation, stabilisation (deshake or two-pass vid.stab), denoise, grain, delogo drawn with the mouse, sharpen, colour / white balance, pad, aspect, picture overlay, pixel format and colour space, CFR / VFR and frame interpolation — also with several trim pieces, in the copied ffmpeg command and in presets; audio delay, gain (previewed on the loudness curve), sample rate, bit depth, mono … 7.1; audio copy or AAC / AC-3 / E-AC-3 / Opus / FLAC / MP3 with stereo / 5.1 and loudness normalisation; per-file track choice; remuxing without re-encoding. 1.4: two-pass encoding for bit rate / file size (NVENC: multipass in one run), several tasks at the same time, a CPU limit («100% ▾»: threads and cores), PSNR / SSIM / VMAF quality metrics and the current frame on the Status tab, a speed test of every encoder on the PC, tasks dragged into order, the task list saved to / loaded from a file, cards or rows, external audio / subtitle tracks with delay and language, joining several files into one task, splitting the result by size or time — all of it with trim and filters, in the copied command and in presets. 1.5: presets of the format (allowed codecs, H.264 / HEVC / AV1 / MPEG-4 profiles and levels, keyframes, VBV, own file extension, audio track / channel limits, a default frame and length; own ones created, renamed, deleted, exported and imported), container options (MKV index space / Cues in front / clusters / CRC32 / default flag, MP4 faststart / fragmented, TS muxrate / PCR), device presets in one grouped list (iPhone / iPad, Android, Samsung / LG / Sony TVs, PlayStation 5, Xbox Series, YouTube, Telegram, Discord 10 / 50 MB, Blu-ray H.264, DVD PAL / NTSC), advanced encoder settings shown only where this FFmpeg build has them (x264 / x265, NVENC p1–p7 / tune / multipass / B-ref / look-ahead / AQ / split encode, AMF / QSV, SVT-AV1, VP9) and a comparison of two presets on a short piece (size, speed, VMAF / PSNR / SSIM). A queue with presets, pause, stop, priority and «when done» actions; a status tab with speed, fps, ETA, system and GPU load and the ffmpeg log; taskbar progress; Explorer context menu; auto-update; Russian / English.
